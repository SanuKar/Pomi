# 🚀 Pomi

> A modular AI workspace built with Python, FastAPI, PostgreSQL, RAG, and LLM APIs.

---

## 📖 Overview

Pomi is an AI workspace designed to demonstrate a complete AI Engineering pipeline. It combines conversational AI, Retrieval-Augmented Generation (RAG), document intelligence, and modern backend engineering into one production-ready application.

This project is being built in public as part of a four-month AI Engineering roadmap.

---

## 🎯 Mission

Build one production-ready AI application that demonstrates modern AI Engineering skills using open-source tools and industry-standard practices.

---

## ✨ Planned Features

- 🔐 User Authentication (JWT)
- 💬 AI Chat (Gemini/OpenAI)
- 📄 PDF Upload
- 🧠 Retrieval-Augmented Generation (RAG)
- 🗂️ Conversation History
- 🐳 Docker Support
- ☁️ Cloud Deployment

---

## 🛠️ Tech Stack

| Category | Technology |
